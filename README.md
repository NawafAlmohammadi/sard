# سَرد · Sard

**الإصدار التجريبي الأول: ألفا (Alpha) — `0.1.0-alpha.1`**

مساحة عربية محلية لبناء عالم الحكاية وكتابة الرواية.

## التشغيل بدون إنترنت

حمّل **Sard-0.1.0-alpha.1.zip** من [صفحة الإصدارات](../../releases) وفك ضغطه. افتح **Sard.html** في إيدج (Edge) أو كروم (Chrome)، أو شغّل **Open-Sard.cmd**. يمكن تحميل **Sard.html** وحده أيضًا. لا يحتاج البرنامج تنزيل مكتبات أو اتصالًا أو حسابًا. هذه النسخة تطبيق ويب محلي يفتح في المتصفح؛ ليست ملف تثبيت مستقلًا بصيغة EXE.

اضغط **ابدأ حكايتك** واكتب اسم عالمك ونبذته. النسخة تبدأ فارغة دون شخصيات أو قصص أو عوالم جاهزة.

## ماذا تستطيع أن تفعل؟

- إنشاء عوالم متعددة وتسميتها بنفسك والتنقل بينها، دون بيانات تجريبية جاهزة.
- إنشاء وتعديل بطاقات الشخصيات بمساحة حرة: الاسم وصورة اختيارية ونبذة تكتبها بطريقتك، وأسماء أخرى وخصائص اختيارية تسمّيها بنفسك. عرض مساحة الشخصية أو شبكة البطاقات. التفاصيل القديمة تُدمج في النبذة للحفاظ عليها، دون فرض خانات للرغبة أو الخوف أو السر.
- تسجيل أماكن القصة بأسمائها ونبذاتها، وربطها بالأحداث.
- ترتيب أحداث القصة زمنيًا مع تواريخ أو حقب خيالية، وربطها بشخصية ومكان وفصل.
- إنشاء روابط بين الشخصيات، وتعديل أنواعها ووصفها، وسحب الشخصيات لترتيب الشبكة.
- كتابة الفصول بحفظ تلقائي، عدّ الكلمات، وضع التركيز، وتصدير المخطوط كنص.
- حفظ الأفكار وقوانين العالم والأسئلة المفتوحة والتفاصيل.
- اختيار خلفية داكنة أو صورة محلية وضبط التعتيم والضبابية وكثافة الزجاج.
- نقل العناصر إلى المحذوفات واستعادتها من الإعدادات.

## الحفظ والنسخ الاحتياطية

يحفظ التطبيق بيانات العوالم وصورها تلقائيًا في قاعدة المتصفح المحلية (IndexedDB) على الجهاز، ويستخدم التخزين المحلي (localStorage) بديلًا عند تعذّر ذلك. رسومات الخرائط القديمة محفوظة كأرشيف ضمن النسخ الاحتياطية فقط، ولا تظهر أدوات الخرائط في البرنامج.

لا توجد خدمة خلفية أو سحابة أو تحليلات أو اتصالات خارجية.

اضغط **نسخة احتياطية** لحفظ جميع العوالم والصور والفصول في ملف بيانات **JSON** على جهازك. لاستعادته، افتح الإعدادات ثم **استيراد نسخة**. تُضاف العوالم المستوردة كنسخ مستقلة، ولا تُستبدل العوالم الموجودة.

الحفظ التلقائي مرتبط بالمتصفح ومصدر التطبيق. بيانات المعاينة المحلية لا تنتقل تلقائيًا إلى Sard.html؛ انقلها بالتصدير والاستيراد. حذف بيانات المتصفح يزيل الحفظ المحلي، لذلك احتفظ بملف نسخة احتياطية. بيانات القصص لا تُكتب داخل ملف البرنامج نفسه.

## المصدر والمعاينة

المصدر في `dist/`، بدون اعتماد على مكتبات خارجية. إذا كان نود (Node.js) مثبتًا، شغّل `npm start` ثم افتح `http://127.0.0.1:4173/`. الخادم يخدم ملفات الواجهة فقط من عنوان الجهاز المحلي. ملف `Sard.html` نسخة مضمّنة من المصدر للاستخدام المستقل. استخدم `npm run check` لفحص صياغة البرنامج و`npm run build` لإعادة بناء الملف المستقل.

التحقق: إنشاء شخصية وحفظها عبر إعادة الفتح، حفظ نص الفصل واسترجاعه، نقل واستعادة عنصر، إضافة وتعديل أماكن القصة، فحص شاشات الأحداث والعلاقات والإعدادات، وفحص صلاحية ملفات الاستيراد. الملف المحلي النهائي يعمل دون طلب موارد خارجية.

## التحديث من النسخة السابقة

الاسم أصبح **سَرد** بفتح السين. أزيل العالم والشخصيات والكتابات التي كانت للتجربة. تزال العوالم التجريبية مع محتوياتها. العوالم المستقلة التي أنشأتها أنت تبقى محفوظة.

## معنى إصدار ألفا

هذه نسخة مبكرة للتجربة وجمع الملاحظات. المزايا الأساسية تعمل، وقد تظهر أخطاء أو تفاصيل تحتاج تحسينًا، خصوصًا اختلافات التخزين بين المتصفحات وتخطيط الشاشات الصغيرة. احتفظ بنسخ احتياطية منتظمة أثناء كتابة قصة طويلة، وقبل تحديث البرنامج أو نقله.

أرسل ملاحظاتك من [صفحة المشكلات](../../issues)، مع وصف الخطوات والنتيجة المتوقعة واسم المتصفح. المصدر لا يحتوي على بيانات قصص المستخدمين أو نسخهم الاحتياطية.
